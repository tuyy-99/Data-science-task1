# Data Science Task 1 — Python Fundamentals

A collection of beginner-level Python exercises focused on core programming concepts including string manipulation, iteration, and function-based logic.

---

## Projects

### Level 1 — Reverse String
**File:** `level1_reverse_string.py`

Takes a user-input word or sentence and returns it reversed using Python slicing.

**Example:**
```
Enter a word or sentence: Hello World
Reversed string: dlroW olleH
```

---

### Level 2 — Vowel Counter
**File:** `level2_vowel_counter.py`

Counts the number of vowels (a, e, i, o, u) in a given string, supporting both uppercase and lowercase characters.

**Example:**
```
Enter text: Data Science
Number of vowels: 5
```

---

### Level 3 — Simple Calculator
**File:** `level3_calculator.py`

An interactive calculator that supports four arithmetic operations: addition, subtraction, multiplication, and division. Includes zero-division error handling.

**Example:**
```
Simple Calculator
Choose operation:
1. Addition
2. Subtraction
3. Multiplication
4. Division
Enter choice (1-4): 4
Enter first number: 10
Enter second number: 0
Result: Error: division by zero is not allowed
```

---

## Getting Started

### Prerequisites
- Python 3.x

### Run any script
```bash
python level1_reverse_string.py
python level2_vowel_counter.py
python level3_calculator.py
```
